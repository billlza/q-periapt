## Reproduce the self-contained checks

Python 3 and its standard library are sufficient. From any directory, supply the script location and a writable receipt path:

```sh
python /path/to/check_interfaces.py --finite-only --output /tmp/confirmation-finite.json
```

This mode reads no Git repository or source checkout. It runs nineteen finite encoding, guessing-bound and counterexample checks. The verifier enumeration uses two messages, four tags and zero through three classical attempts: 585 deterministic all-failure-prefix strategies over sixteen random tables, for 9360 table executions. This is executable support for the written interface argument and does not constitute a formal proof of the quantum bound.

The JoC workflow may run this same finite-only command and retain its own workflow-specific receipt. A local receipt and a remote workflow outcome keep their separate execution identities.

## Reproduce the pinned-source audit

The full audit additionally needs Git repositories containing the following references, and native/development worktrees with the reviewed source bytes:

- Native source: `228c944fc476e3e57d6c08063cacb19bca5b360e`.
- Development source: `1c68aa666db22d36ee136be1ec712545a9e74f03`.
- Original manuscript dependencies: `da521d8388f5f0c64697387bf80b0b5b7837fb34`.

```sh
python /path/to/check_interfaces.py \
  --native-repository /path/to/native-checkout \
  --development-repository /path/to/development-checkout \
  --paper-repository /path/to/paper-checkout \
  --output /tmp/confirmation-source-checks.json
```

Each repository argument defaults to the current directory, so a complete clone containing all three references can supply one path for all of them. A shallow clone must already contain the declared references before this command is meaningful. The script performs no fetch or checkout. It requires exact reviewed native/development source bytes and hashes the manuscript dependencies from the fixed original commit.

The full run has thirty-nine checks: the nineteen self-contained checks and twenty source identity/interface assertions. It does not execute Rust, Tamarin or a new proof assistant. Earlier native and formal receipts remain separately identified.
