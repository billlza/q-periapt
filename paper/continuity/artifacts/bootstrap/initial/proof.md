## Result

One surviving initial PQ contribution supplies a concrete schedule comparison
even when the responder signing identity, all traditional KEM material and
the later reply contributions are available. The original prekey generation
and Initial encapsulation determine the hidden first contribution. Its SDK
confirmation is evaluated before any Reply exists. The same contribution
subsequently supports the adaptive family of 64-byte bootstrap Extracts.

The proof preserves that order through one joint short/long interface. It
first localizes the terminal test to an original source pair, performs the
component and joint-entry comparisons once, and then localizes the resulting
private PRK table to one online allocation rank. Consequently the number of
later PRK families multiplies the terminal-tail terms only. Initial and Reply
signature aliases retain their actual complete-wire bindings throughout.

The encrypted-record acquisition partition is the one already established
for the [reply-source adapter][reply]. Its exact two-endpoint residual is
retained here; the no-acquisition interface has zero residual. This result
adds the original initial-source construction and the two-level accounting.

## 7. Initial-source schedule theorem

**Theorem 5 — two-level initial-source connection.** For the profile above,
with the exact raw-acquisition residual and the complete budgets just stated,

```text
epsilon_schedule <= min(1,
  sum_{r=1..R} [
      alpha_r,0 + alpha_r,1 + eta_cap,r
    + sum_{j in [G] x [A]} sum_{b in {0,1}} [
        E_rj,b + sum_{ell=1..L_j} T_rjell,b
      ]
  ]).
```

If `L_j<=L` and all component budgets admit common upper bounds, this gives

```text
epsilon_schedule <= min(1,
    2 R alpha + sum_r eta_cap,r
  + 2 R G A [nu_enc + rho + a + delta + Phi_256(d,Q_CB)
             + Delta_entry + L (D_tail + chi_h(Q_h))]).
```

**Proof.** Telescope the adjacent ACK replacements and charge each endpoint's
association monitor. The absent-registration terms cancel. Lemma 3 localizes
the remaining test to fixed original pairs without promoting a source
opened before registration. The immutable acquisition modification contributes
the exact `eta_cap,r`; the first-stage record, component, ContextBound and
joint-entry comparisons contribute `E_rj,b` for each endpoint.

At this point the long PRKs form `VB`. Partition the transformed candidate
bit by its online allocation rank. Lemma 4 installs a selected independent
parent at its first request and justifies precisely its opening stops.
Each terminal-tail comparison costs `T_rjell,b`; the two full-table endpoint
scores coincide. Apply the triangle inequality, then sum the ranks, original
pairs and registration indices. Since the second partition occurs after the
joint-entry replacement, it multiplies only the subsequent tail costs.
This proves both displayed expressions. **QED.**

The U1 substitution is now source anchored:

```text
Pr[latched Bad] <= min(1,
    Pr_real[Coll] + epsilon_schedule + epsilon_mac
  + q_v / (2^256 - q_v + 1)).
```

For the interface with no successful raw acquisition of the marked versions,
`eta_cap,r=0`. With permitted capture its two-endpoint value remains the exact
record term. The initial confirmation, responder-signing compromise, adaptive
known reply contribution and later family openings retain their declared
interfaces in both cases.
