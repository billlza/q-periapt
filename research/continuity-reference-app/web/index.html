Device enrollment
reference app.

This local application demonstrates account authorization for device enrollment. Using the Q-Periapt SDK does not require this account or a passkey; your application can supply its own authentication and trusted provisioning.

For this example, use a passkey to create a local test account or sign in. Your device handles the biometric or PIN check; this application never receives it.
