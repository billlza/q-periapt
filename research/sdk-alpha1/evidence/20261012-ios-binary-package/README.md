# Installed iOS binary-package checkpoint

`QPeriaptContinuity-ios-candidate.zip` is an unpublished local Swift package. Extract it, add the `QPeriaptContinuity` directory as a local package dependency, link its `QPeriaptContinuity` product and import that module. The package supplies the current 24 Swift library files, exact C header and static XCFramework. The consuming application needs no Rust toolchain, custom SDK header search path, custom library search path or manually named SDK archive.

The XCFramework contains arm64 iOS device and arm64 iOS simulator slices. It declares an iOS 16 source floor; the physical execution below is on iPadOS 27.0.1. Intel Mac/simulator support is outside scope. Generic simulator Release builds explicitly select `ARCHS=arm64`. Supply your independently approved trust/provisioning materials through the [public Swift API](../../../../bindings/swift/ContinuityPackageConsumer/README.md); the package does not provide a trusted issuer fixture for applications.

The package includes its own licenses, resolved dependency license texts and Rust standard-library copyright/license material. All 269 archive members are checked after extraction.
