# Two successive Android joint policy and credential renewals

Six fresh host Java/JNI routes completed two actual G/T generations on each
original installation, journal and session: local, signed TCP and mutual TLS,
each with fixed and recoverable trust. All 434 foreign process invocations
passed. Six concurrent native tests took 552.29 seconds including public export
and readback, within the unchanged 900-second command bound. This is test
qualification duration, not an application latency measurement.

The accepted API 37 arm64 phone separately completed the TLS/recoverable route
with the signed R8 APK: 80 distinct ART processes, each stopped and observed
absent after its operation. The original application message remained unresolved
through both renewals, then retried under the same message identity with one
retained business effect. Both routes observed three real policy expiries;
historical reconciliation remained distinct from current-policy admission.
The owned application was removed and a direct ADB readback found no reverse
port mappings. No second phone or API 36 device is required by this acceptance.

G2 uses the public continuation emitted after G1 and carries actual T1/P1 and
the renewed credential and roster, while preserving original C/R/P0. Invalid
approval (102), missing predecessor (105) and incorrect predecessor (103) are
rejected without changing the previous Committed result. Each witnessed
generation loses a real Commit reply (218), then an explicit Close observes
Applied; passive historical reconciliation emits neither Commit nor Close.
After P2 expires, the next public request retains actual T2 as its predecessor.

The first signed-host attempt failed correctly: the fault server's fixed
`witness-cancelled-prefix` filename collided between generations before the
second Commit capture was appended. Its failed receipt is retained in
`HOST_CAPTURE.zip`. Each generation now owns a distinct fault directory;
exclusive creation and all Commit/Close assertions are unchanged. Fresh
replacement cohorts passed. A further fresh single-generation signed/fixed
Applied regression passed all 49 Java/JNI invocations.

Only qualification fixtures, readers and CI admission changed. The Android
public API, JNI dispatch and protocol engine did not change. The AAR and runtime
JAR are the retained package inputs; the native test harness and R8 test APK
were rebuilt. `HOST_CAPTURE.zip` and `DEVICE_CAPTURE.zip` retain exact hashes,
public transcripts and terminal receipts. `CHECKS.zip` adds final reader tests,
format checks and the single-generation regression without rewriting those
captures. Private fixture state and executable artifacts remain local.

The six host routes use the Debug harness. CI now requires this complete batch
in both installed Debug and Release profiles, and uploads its public records.
This evidence does not replace that CI run, an independent protocol
implementation, identity-key rotation, PCS analysis or the remaining 0.2.0
release requirements. No accepted or protected old cohort was reopened.
