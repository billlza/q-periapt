# Full SummaryStats equality on an existing nonempty Rust fixture

The original fixed `all` plan and the Stage4 target-projection plan both completed
the full `SummaryStats` query on the existing CodeQL environment-source fixture.
All 29 decoded rows, column descriptors and result-set structure are identical.
The input contains 15 active threat-model sources and 106 tainted nodes. This
closes the nonempty fixture execution and result-equivalence check for these two
fixed capsules.
