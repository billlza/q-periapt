The producer turns the exact library already exercised by the installed
Debug/Release C qualification into a versioned native archive. It preserves the
158-function `qpc-owner/1` interface, original library bytes, source identity and
the existing C execution receipt. Independent archive extraction, native loader
inspection and a newly compiled relocated C probe run before the producer emits
its distribution identity and release-manifest package row.
