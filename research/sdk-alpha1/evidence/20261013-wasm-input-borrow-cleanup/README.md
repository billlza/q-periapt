# WASM byte-input borrow cleanup

The actual installed prerelease reproduced a binding cleanup defect. A Uint8Array Proxy, a throwing own `length` getter, and a false own length caused JavaScript exceptions to escape `read_input` through uncaught typed-array imports. Later `free()` failed with a borrowed-Rust-value error. The new regression also exercises key and secret owners, so an ordinary operation result is not mistaken for successful cleanup.

The input boundary now uses genuine typed-array internal-slot getters and an intrinsic copy, imported with `wasm-bindgen catch`. It does not invoke caller `length`, buffer, iterator, species or tag properties. Non-Uint8Array values and proxies fail explicitly; real subclasses and cross-realm Uint8Arrays retain their actual bytes. Detached/out-of-bounds copy failures return through Rust, preserve the original exception as `cause`, and let the temporary wiping buffer and owner borrow guards drop. This fixes input handling and lifetime reliability; these owners are not isolation from malicious same-realm JavaScript.

`CHECKS.json` and `CAPTURE.zip` bind the old and final installed archive identities, exact source overlay, same-test red/green outcomes, raw probes, final package consumers and browser results. The final standalone regression passes 58 checks. The installed Node consumer additionally covers a foreign VM realm; the browser runs the same cases in a window and a dedicated Worker, with a foreign iframe realm in the window. Exact roundtrip assertion totals increased from 178 to 243/236. All ten browser modes pass. The final package also passes Node 24.0.0 with its bundled npm 11.3.0, Node 26, strict TypeScript, native/WASM Clippy, Rust 1.90 WASM checking and 53 artifact controls.

A fresh, required-witness Continuity device rejects four bad asynchronous inputs without invoking their getters, retains its original phase/journal identity, then completes targets 1–3 and authenticated application delivery in both directions. This is real browser persistent-owner evidence using the same Rust engine and loopback endpoints. Private fixture keys, wrapping material, journal databases and browser profiles are excluded.

Non-admitted attempts remain recorded: a regression-driver import-path mistake, an invalid test protocol label, the outdated assertion-count sentinel, and selecting npm 12 for the minimum Node runtime. The test label was corrected to the existing allowed `input/v1`; exact counts were raised, not removed; the minimum-runtime consumer was rerun with its own supported npm. No error was converted to success or warning suppressed.

This record does not qualify all browser/device versions, deployed HTTPS, independent implementations, performance, secrecy recovery or the full 0.2.0 release. Node 24 was unpacked into this task's private tool directory from the official archive and checked against its published digest; no global installation occurred.
