# Registered publication through Rust and C owners

The component uses the actual registered identity/signing owner, persistent
journal and existing C parent invocation boundary. Debug and Release C workloads
prepare four-role manifests, reopen in new processes and recover byte-identical
QPPUBA01 artifacts, verify each signature/membership proof, reject a short output
buffer without mutation, cancel an unallocated next operation, retire acknowledged
history and then complete normal TLS/application traffic. Both public readbacks
are retained alongside logs and exact source hashes.

A targeted test found a member expiring at final release while its policy and
manifest remained valid. `publication-leaf-expiry-red` failed before the fix;
`publication-leaf-expiry-green` passed after every member's interval was added to
final admission. The updated 24-case native publication suite passed Debug and
Release. Rust 1.90, strict native/C Clippy, 13 C-boundary tests per profile and
29 Python reader regressions also passed. Full native/source preflight for this
new interface checkpoint remains separate from the prior 814/2,663-test receipt.

The C API has 125 unpublished candidate exports, with exact header/library/gate
agreement; product SDK ABI 2 remains unchanged. Builds use source-linked native
dependencies, so this is not qualification of a complete distribution archive.
Swift/Kotlin publication, the installed successor advertisement path, platform/
physical-device coverage, independent implementation and security/recovery analysis
remain open. No remote directory publication or release was performed.
